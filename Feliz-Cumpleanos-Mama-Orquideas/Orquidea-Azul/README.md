# 💙 Orquídeas Azules

Proyecto estilo tarjeta con fila de orquídeas azules (inspirado en el diseño de girasoles).

## Cómo usarlo

1. Abre `index.html` en el navegador
2. Haz clic en el botón para ver las orquídeas

## Personalizar

### Mensaje
Abre `orquidea.html` y busca:

```html
<!-- ====================== -->
<!--  AQUÍ ESCRIBE TU MENSAJE  -->
<!-- ====================== -->
```

Cambia el texto de `.love-text` y `.sub-message`.

### Música / Audio
1. Coloca tu archivo de audio (`.mp3` o `.m4a`) en la carpeta `sound/`
2. En `orquidea.html` cambia el nombre del archivo en la etiqueta `<audio>`:

```html
<audio id="audio" src="sound/mensaje-mama.m4a" preload="auto"></audio>
```

¡Listo!
